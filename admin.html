Вход

Где взять токен
  1. Открой создание токена.
  2. Repository access: Only select repositories, выбери репозиторий гардероба.
  3. Permissions, Repository permissions: Contents: Read and write.
  4. Generate token, скопируй и вставь сюда.

Токен лежит только в твоём браузере и уходит только на api.github.com. Без него страница ничего не умеет, поэтому посторонние ничего не изменят.
